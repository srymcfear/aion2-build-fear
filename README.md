# FEΔR — AION 2 Gear & Soul Sync Planner

Trang web và báo cáo Excel tổng hợp chỉ số nâng cấp **Soul Binding (PvE & PvP)** và **Arcana** cho các thành viên Legion **FEΔR** (Zikel · Asia).

## Thành viên hiện có
- **TheAres** (Gladiator · Lv. 45)
- **KingDoggo** (Templar · Lv. 45)
- **MusangKing** (Cleric · Lv. 45)
- **TEDs** (Ranger · Lv. 45)
- **BER** (Assassin · Lv. 45)
- **HHeo** (Chanter · Lv. 45)

## Cấu trúc thư mục
- `index.html`: Trang web chính (hỗ trợ PvE/PvP, bộ lọc ưu tiên, đối chiếu `YOUR LINES` vs `AIM FOR` kèm `Per Sync`, và chi tiết Arcana kèm icon skill).
- `*_Upgrades_Summary.xlsx`: Báo cáo Excel chi tiết từng thành viên (PvE & PvP).
- `demo-*.html`: 3 mẫu prototype ban đầu.
